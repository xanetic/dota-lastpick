# Угадай ластпик · Dota 2

Мини-игра: берётся случайный матч с The International, показываются оба драфта,
но **последний выбранный герой (ластпик) скрыт**. Нужно его угадать.

- Из информации: 9 остальных героев + название турнира.
- **Подсказка 1** — открывает названия команд.
- **Подсказка 2** — открывает ники про-игроков и на ком они играли.
- Выбор героя — полная таблица как в доте, разбитая по атрибутам
  (Сила / Ловкость / Интеллект / Универсалы), с поиском по имени с клавиатуры.

## Данные

Берутся из **OpenDota API** (бесплатно, без ключа). Картинки героев — с CDN Valve.
Dotabuff парсить напрямую мешает Cloudflare, поэтому источник — OpenDota (те же данные, чистый JSON).

Файлы данных лежат в `data/` и уже сгенерированы. Чтобы перекачать/расширить:

```bash
python3 fetch_data.py                  # дефолт: по 30 матчей с каждого Интернешнла
python3 fetch_data.py --per-league 60  # больше матчей (дольше из-за rate-limit)
```

Список турниров и годы задаются в начале `fetch_data.py` (словарь `INTERNATIONALS`).

## Запуск

Сайт — чистая статика, но из-за `fetch()` его надо открывать через локальный сервер
(не двойным кликом по файлу):

```bash
cd dota-lastpick
python3 -m http.server 8000
```

Открыть в браузере: **http://localhost:8000/**

## Управление

- Просто начни печатать — фокус прыгнет в поиск, таблица отфильтруется.
- `Enter` — если виден ровно один герой, выбрать его.
- `Esc` — очистить поиск.
- «Новая игра» — следующий случайный матч (учитывает фильтр по году).
